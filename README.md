## 📌 Sobre o Projeto

Este repositório registra a minha evolução prática no aprendizado de **Python 3**, acompanhando a resolução dos exercícios do **Mundo 1 do Curso em Vídeo (Prof. Gustavo Guanabara)**.

O objetivo do projeto não é apenas armazenar códigos de estudo, mas documentar a construção diária da minha base em lógica de programação. Cada script foi desenvolvido para resolver um problema específico, evoluindo do simples recebimento de dados no terminal até a automação de cálculos matemáticos e conversores do dia a dia.

---

## 💡 O que os Scripts Fazem (Exercícios Desenvolvidos)

Atualmente, o repositório contém os algoritmos do início do módulo, focados em interatividade via terminal, tipos primitivos e operadores aritméticos:

### 1. Interação Básica e Entrada de Dados
* **Boas-vindas e Leitura:** Scripts iniciais de captura de dados via teclado (`input`), tratamento de tipos de variáveis e exibição de mensagens personalizadas.
* **Dissecando Variáveis:** Análise detalhada do conteúdo digitado (identificação se é numérico, alfabético, maiúsculo, minúsculo ou alfanumérico).

### 2. Operações Aritméticas e Manipulação Numérica
* **Antecessor e Sucessor:** Leitura de números inteiros com cálculo e exibição imediata dos seus vizinhos numéricos.
* **Análise Numérica:** Algoritmos para cálculo instantâneo do dobro, triplo e raiz quadrada de um valor digitado.
* **Calculadora de Média:** Processamento de notas escolares para cálculo de média aritmética simples.
* **Gerador de Tabuada:** Automação que gera a tabuada completa de qualquer número inteiro digitado.

### 3. Conversores Práticos
* **Conversor de Medidas:** Leitura de valores em metros com conversão automática para centímetros e milímetros.
* **Conversor de Moedas (Exercício 010):** Algoritmo que recebe um valor em Reais (R$) e calcula a capacidade de compra em Dólares (US$), aplicando conversão cambial.
